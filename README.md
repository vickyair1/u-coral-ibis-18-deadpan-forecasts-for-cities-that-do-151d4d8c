# Deadpan Forecast — Quibbleford

Entry for the [Deadpan Forecasts for Cities That Do Not Exist](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c) bounty on make.fun.

> "In Quibbleford, expect a high of 14 degrees, light drizzle and winds of 20 km/h, with a 90% chance the fog sues the sun for defamation before noon."

A deadpan weather forecast for a city that does not exist — 147 characters, one line, delivered by a deterministic Python program.

## Run

```sh
python3 main.py
```

Writes the forecast to `/output/entry.txt` (no trailing newline) and prints it to stdout with no trailing newline.
